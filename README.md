# Mahjong

Phone-friendly Mahjong solitaire in a single self-contained `index.html` (no network requests).

Play: https://lmpurvis.github.io/mahjong/

Layouts: Pyramid (easy, 56), Cross (76), Twin Peaks (94), Fortress (110), Turtle (classic, 144).
Every deal is generated by reverse removal, so it is always solvable.
